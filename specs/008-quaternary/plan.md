# План: лист «Четвертичные образования» по образцам легенды

- `pipeline/swatch_table.py`: таблица `SHEETS` (лист → `[(индекс, x, y)]`), `sample`, `inks`
  (краски и индексы образцов каждой краски), `palette`.
- `pipeline/build.py`: `by_legend` принимает готовую палитру. Для листа из таблицы проход
  оставляется без `legend.keeps_legend`: поиск образцов на этом листе находит 0 образцов до прохода и после.
- `tests/test_swatch_table.py`: одна краска у близких образцов, индекс внутри образца не сдвигает
  цвет, 50 образцов листа в пределах изображения.
- Пересборка одного листа: `build.py --ids FILE --force`. Сборка идёт в отдельной копии проекта
  (`atlas-russia-vector-quat`): папки `data/` и `site/public/data/` вне git.
- Публикация на atlas.ebpm.center — после слияния ветки в `main`, отдельным шагом.
