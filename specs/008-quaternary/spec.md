# Спецификация: лист «Четвертичные образования» по образцам легенды

**Папка**: `specs/008-quaternary` | **Создана**: 2026-10-29 | **Статус**: лист пересобран на iMac,
на сайте не опубликован

**Запрос**: продукт poraOtdihat (фича 279, T008) грузит лист `2-60-62-1` слоем карты. Для слоя
нужна подпись каждого класса.

## Проблема

Легенда листа — таблица: 17 генетических типов (столбцы) × 5 возрастов (строки), 49 образцов, и
образец «Дочетвертичные образования». Всего 50 образцов. Первый проход дал 32 цвета. Из них 23
цвета лежат внутри контура страны. Цвет образца и ближайший цвет вектора расходятся до 77 ΔE (RGB):
вектор слил соседние знаки, и подпись выбрать нельзя.

Второй проход по цветам легенды (фича 004) этот лист пропустил: `legend.swatches` нашёл 0 образцов.
В каждом образце напечатан индекс («dH», «gII»), у полигона образца есть дыры, и поиск отбрасывает
такой полигон.

## Требования

- **FR-001**: Таблица `pipeline/swatch_table.py` несёт центр и индекс каждого образца листа. Координаты сняты с изображения `data/img`, легенда просмотрена человеком.
- **FR-002**: Цвет образца — медиана коробки 23 × 11 px внутри рамки. Напечатанный индекс медиану
  не сдвигает.
- **FR-003**: Образцы ближе `legend.SAME_COLOUR` (3,5 ΔE) делят один класс. Порядок классов —
  порядок таблицы.
- **FR-004**: Лист из таблицы идёт вторым проходом `build.by_legend` без условий о числе найденных
  образцов. Условие `no_vector` остаётся.
- **FR-005**: Вектор остальных листов не меняется.

## Проверка

- Классов у образцов листа не меньше 45 из 50: класс делят только образцы одной краски.
- Внутри контура страны цвета вне легенды занимают не больше 3 % площади.

## Вне рамок

- Подписи `l/2-60-62-1.json` для сайта. Таблица несёт индексы, а не текст легенды.
- Штриховка морских отложений («mv», «mn», «mp», «mba»). Класс берёт средний цвет образца со
  штриховкой.
- Подробность контуров. Сглаживание второго прохода сливает узкие полосы элювия с делювием.
