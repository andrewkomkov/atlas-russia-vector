# План: листы животного мира с ручной разметкой

## Формат разметки `marks/<id>.json`

| Поле | Значение |
| --- | --- |
| `source`, `made` | что переписано, с какого изображения, когда |
| `legend.items[]` | `key`, `swatch: [x, y, w, h]`, `label`, `text`, `group`, `kind` (`nodata`, `outside`), `variant_of` |
| `units.seeds[]` | `[ключ, x, y]` — точка внутри выдела |
| `units.areas[]` | `{key, xy}` — контур варианта, отличного только штриховкой |
| `units.page` | `file`, `start`, `stop`, `fixes` — текст выделов со страницы атласа |
| `units.text` | текст выдела, если его нет ни в легенде, ни на странице |
| `units.band` | краска государственной границы: выдел не растёт вдоль полосы |
| `units.snap`, `units.by_colour`, `units.relief`, `units.water` | настройки роста |
| `inks[]` | `kind`, `rgb`, `de`, `box`, `exclude`, `as` (`points`, `lines`) — знак одной краски |
| `points[]`, `lines[]` | `kind`, `key`, `xy` — знаки, поставленные рукой |

## Рост выдела

1. Суша — полигоны вектора внутри контура страны без классов воды. Дыры меньше 0,04 % листа —
   суша (белая штриховка, озёра).
2. Рельеф — перепад цвета очищенного листа (`vec.clean`) на 4 px, граница класса вектора,
   по выбору серые штрихи.
3. Каждая точка суши получает ближайшую точку разметки по пути внутри суши. Шаг стоит
   `1 + (рельеф / 12)²`. Сумма, а не наибольший шаг: первая проба (`watershed_ift`) пускала
   выдел по тонкому коридору вдоль полосы границы через весь лист.
4. Полоса границы своей краски не суша; её точки получают ближайший выдел после роста.
5. Точка разметки сдвигается на пиксель цвета своего образца в радиусе `snap`.
6. Контуры `areas` перекрывают выросшие выделы.

## Знаки одной краски

Маска цвета внутри рамки → связные пятна. Пятно короче `point` px — точка. Длинное пятно:
пунктир сшивается закрытием, утончается (Zhang–Suen) и обходится в ломаные.

## Выход `a/<id>.json`

`v` — отпечаток слоя; `legend.classes` — `{класс: [знаки]}`, `legend.lost`;
`units.keys`, `units.info` (текст), `units.f` — `[номер ключа, 1, кольца]` как в `v/`,
`units.share`, `units.none`; `points[]` — `{kind, key, x, y}`; `lines[]` — `{kind, key, xy}`.
