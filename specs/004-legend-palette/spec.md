# Спецификация: цветовые классы по легенде

**Папка**: `specs/004-legend-palette` | **Создана**: 2026-10-12 | **Статус**: проба на 2 картах опубликована 2026-10-12

**Запрос**: «попробуй на 1–2 и сделай всё суперидеально».

## Проблема

Вектор различает до 32 цветов, а подробная легенда содержит больше знаков. На карте
растительности `2-328-330-1` — 130 знаков. Соседние цвета легенды попадают в один класс,
и класс остаётся без подписи. Вторая причина: один цвет легенда использует для нескольких
знаков и различает их номером на карте.

## Сценарий (P1)

Пользователь наводит курсор на полигон подробной карты. Если цвет полигона в легенде один,
подсказка показывает подпись знака и его номер. Если этот цвет в легенде у нескольких
знаков, подсказка показывает их список с номерами. По номеру на листе пользователь
выбирает нужный знак.

**Проверка**: на карте `2-328-330-1` подпись или список вариантов есть не меньше чем
у 80 % площади внутри контура России.

## Требования

- **FR-001**: Для карты из списка пробы конвейер строит цветовые классы по цветам образцов
  легенды. Цвета вне легенды добавляет прежний способ (k-средних).
- **FR-002**: Образцы с разницей цвета меньше 3,5 единиц ΔE получают один класс.
- **FR-003**: Класс с одним знаком получает подпись. Класс с 2–6 разными знаками получает
  список вариантов (`alts`). Класс с большим числом знаков остаётся без подписи.
- **FR-004**: Номер условного знака конвейер хранит отдельно (`nums`) и показывает рядом
  с подписью.
- **FR-005**: Конвейер исправляет редкое латинское слово легенды на частое слово той же
  легенды, если слова отличаются одной буквой.
- **FR-006**: Сайт показывает список вариантов в подсказке и в списке классов.
- **FR-007**: Список пробы записан в `pipeline/build.py`. Вектор остальных карт не меняется.
- **FR-008**: Увеличенное чтение легенды конвейер делает для всех карт с образцами.
  Для крупной легенды он берёт его, только если оно нашло на четверть больше знаков.

## Вне рамок

- Чтение номеров знаков, напечатанных на карте. Проба 2026-10-12: Apple Vision читает
  около 15 номеров из 100 даже после поворота фрагмента.
- Перенос способа на все карты. Решение — после пробы.

## Критерии успеха

- **SC-001**: Критерий сценария P1 выполнен на `2-328-330-1`.
- **SC-002**: На второй карте пробы подписанных классов стало больше, чем было.
- **SC-003**: Данные остальных карт после пересборки легенд не хуже: число карт
  с подписями не меньше 655.

## Итог пробы

- SC-001 не выполнен: подпись или список вариантов есть у 78 % площади, цель — 80 %.
  Точная подпись — у 44 %, список вариантов — у 35 %. До пробы было около 2 %.
- SC-002 выполнен: на `4-196-197-1` стало 48 подписей и 7 списков, было 5 и 6.
- SC-003 выполнен: карт с подписями 735.
- Третья карта, `1-360-363-1` «Почвы», подписей не получила: её легенда устроена иначе.
  Карта возвращена к прежнему виду.
