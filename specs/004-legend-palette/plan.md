# План: цветовые классы по легенде

**Спецификация**: [spec.md](spec.md) | **Дата**: 2026-10-12

## Конвейер

1. Первый проход — прежний: `vec.process` с k-средними. Он нужен, чтобы найти образцы.
2. `legend.palette(doc, im)` берёт медиану цвета внутри каждого образца на очищенном
   изображении и объединяет близкие цвета (ΔE < 3,5).
3. Второй проход: `vec.process(..., palette=...)`. Центры классов — цвета палитры плюс
   центры k-средних, которые дальше 6 единиц ΔE от любого цвета палитры.
4. `smooth_labels` хранит только текущий максимум голосов, а не массив на все классы.
   Иначе 150 классов требуют больше 600 МБ памяти.
5. Список пробы — константа `LEGEND_PALETTE` в `pipeline/build.py`.

## Подписи

- `legend.read_items` возвращает знаки легенды: класс, номер, текст, заголовок.
- `legend.decode` собирает из них `labels`, `nums`, `alts`, `groups`.
- `legend.harmonise` исправляет редкие латинские слова по частым словам той же легенды.
- `legend.columns` делит колонку образцов на блоки, если её разрывает карта.
- `legend.own_lines` отделяет номер знака и обрезает текст на номере следующего знака.
- `ocr_legends.py` читает области легенд всех карт. Тайм-аут — 90 секунд на лист:
  Apple Vision изредка зависает.

## Формат `data/l/<id>.json`

К прежним полям добавлены:

- `nums`: номер знака для класса с одной подписью
- `alts`: список строк «номер · подпись» для класса с несколькими знаками

## Сайт

Подсказка для класса с `alts`: строка «один из N знаков этого цвета» и список.
В списке классов — та же строка и варианты мелким шрифтом.
