# План: чистка данных и кода

**Спецификация**: [spec.md](spec.md) | **Дата**: 2026-10-12

## Порядок работы

Работа идёт двумя запросами на слияние, второй опирается на первый.

1. Ветка `003-cleanup-data`: правило `nv`, фильтр подписей, показ листа как картинки.
2. Ветка `003-cleanup-code`: разбор `app.js`, модуль `proj.js`, тесты, воркер, заголовки,
   поля каталога.

## Данные

- Правило `nv` — функция `no_vector(meta)` в `pipeline/build.py`. Она возвращает `empty`,
  `noise` или `None`. Константы: `MIN_POLYGONS = 6`, `MAX_POLYGONS_UNREF = 1500`.
- Порог 1500 выбран по листам-превью. Выше порога без привязки лежат космоснимки,
  рельефные и старинные карты. Привязанные карты с большим числом полигонов — это
  геология и почвы, их правило не трогает.
- Сборка каталога удаляет `v/<id>.json` помеченного листа. Обработчик `one()` строит
  слой заново, если файла нет, а лист не помечен. Так изменение порога не требует `--force`.
- `build_legends.py` пропускает помеченные листы. Фильтр подписей — в `legend.decode`.
- `check.py` требует вектор только для листов без пометки. Для помеченных он требует,
  чтобы вектора не было.

## Сайт

- Помеченный лист открывается в режиме «Лист» без векторного слоя. Размер листа сайт
  берёт из полей `w` и `h` каталога.
- Модули ES без сборки: `app.js` импортирует `proj.js`. Это не нарушает принцип IV.
- Политика CSP: скрипты и стили только свои, рабочие потоки MapLibre через `blob:`,
  плитки и стиль подложки с `tiles.openfreemap.org`. Атрибуты `style` у образцов цвета
  требуют `style-src 'unsafe-inline'`.
- Зона `ebpm.center` сама вставляет счётчик Cloudflare Web Analytics. Политика разрешает
  его скрипт с `static.cloudflareinsights.com` и отправку на `cloudflareinsights.com`.

## Проверка

- `tests/test_proj.py` (unittest) запускает `node` с `proj.js` и сравнивает с `geo.inv`.
- `tests/test_legend.py` проверяет фильтр подписей на синтетической легенде.
- Локальный запуск `wrangler dev` и проход Playwright до публикации, затем на живом сайте.
