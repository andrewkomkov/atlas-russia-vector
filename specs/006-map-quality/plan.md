# План: качество векторов десяти карт

- Пограничная полоса: цвет границы определяется на листе как самый частый узкий розовый контур
  вокруг суши. Пиксели этого цвета `vec.clean` относит к «чернилам» и заливает соседним цветом.
- Островки: после квантования связные области меньше порога заливаются цветом окружения.
  Порог — площадь подписи: высота строки легенды в квадрате.
- Штриховка: окно 32 × 32 пикселя, в нём автокорреляция по направлениям. Пик с постоянным шагом
  при двух цветах — штриховка. Такие пиксели получают класс «фон + узор».
- Ленточные классы: маска рек строится тоньше, чем ширина ленты класса.
- Шкальная легенда: распознанные числа под полосой цветов дают границы интервалов.
- Привязка 2-412-1: ручная проверка `qa_georef.py`.
- Проверка — листы пар «оригинал | вектор» и `pipeline/check.py` по всему атласу.
