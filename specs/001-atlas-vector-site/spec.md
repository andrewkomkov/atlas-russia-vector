# Спецификация: векторный Национальный атлас России

**Папка**: `specs/001-atlas-vector-site` | **Создана**: 2026-10-12 | **Статус**: в работе

**Запрос**: «оцифровать картинки атласа nationalatlas.ru — перевести в карту, весь сайт, не
только зайцев; выложить на Cloudflare Workers на ebpm.center; сайт современный; оригиналы
можно скачать».

## Сценарии

### 1. Просмотр тематической карты на глобусе (P1)
Пользователь открывает сайт, выбирает карту (например, «Ресурсы зайцев») и видит её
векторные полигоны на интерактивной подложке: можно приближать, наводить на полигон,
включать и выключать классы по цвету, менять прозрачность.

**Проверка**: карта `tom2/383` открывается, контур совпадает с побережьем подложки.

### 2. Каталог всего атласа (P1)
Пользователь видит все карты четырёх томов, сгруппированные по томам и разделам, ищет по
названию и открывает любую карту по прямой ссылке.

### 3. Режим «лист» (P1)
Для карты без географической привязки (региональные листы, старинные карты, космоснимки)
пользователь видит оригинал и векторный слой поверх него в координатах листа, с ползунком
прозрачности.

### 4. Скачивание (P2)
С каждой карты пользователь скачивает оригинальное изображение и векторный слой в GeoJSON.

## Требования

- **FR-001**: Конвейер обходит тома 1–4 сайта и собирает все изображения с атрибутом
  `data-zoom-image` вместе с томом, разделом и названием страницы.
- **FR-002**: Каждое изображение преобразуется в полигоны однородного цвета; подписи,
  реки и тонкие линии удаляются перед выделением полигонов.
- **FR-003**: Карты всей России в стандартной проекции атласа привязываются автоматически
  по контуру страны; привязка принимается только при прохождении порога качества.
- **FR-004**: Сайт показывает привязанные карты на подложке (MapLibre GL, глобус), а
  непривязанные — в режиме «лист».
- **FR-005**: У каждой карты есть: ссылка на источник, скачивание оригинала, скачивание
  GeoJSON, постоянный адрес.
- **FR-006**: Сайт опубликован на Cloudflare Workers по адресу `atlas.ebpm.center`.
- **FR-007**: Сайт имеет светлую и тёмную тему и работает на телефоне.

## Вне рамок

- Распознавание легенд: полигоны получают цвет, а не текстовое значение класса. Значение
  класса читается по легенде на оригинале.
- Привязка региональных листов, карт мира и исторических карт.
- Векторизация линейных и точечных знаков (реки, дороги, значки).

## Критерии успеха

- **SC-001**: В каталоге есть все изображения с `data-zoom-image`, найденные обходом.
- **SC-002**: Для каждой карты каталога существует векторный файл и оригинал.
- **SC-003**: Эталонная карта `tom2/383` привязана со средней ошибкой не больше 10 пикселей
  оригинала.
- **SC-004**: `https://atlas.ebpm.center` отвечает 200 и открывает карту по прямой ссылке.
