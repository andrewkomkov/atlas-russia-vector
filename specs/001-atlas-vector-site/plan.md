# План: векторный Национальный атлас России

**Спецификация**: [spec.md](spec.md) | **Дата**: 2026-10-12

## Технический контекст

- **Конвейер**: Python 3.14, numpy, opencv-python-headless, scipy, shapely. Окружение `.venv`.
- **Сайт**: статический HTML/CSS/JS (ES-модули, без сборки), MapLibre GL JS 5 в
  `site/public/vendor/`. Подложка — стили OpenFreeMap (positron, dark).
- **Хостинг**: Cloudflare Workers Static Assets, `wrangler.jsonc`, домен
  `atlas.ebpm.center` (зона `ebpm.center` в аккаунте пользователя).
- **Проверка**: скрипт `pipeline/check.py` (полнота данных) и Playwright-проверка сайта.

## Структура

```
pipeline/
  crawl.py      обход страниц томов 1–4, кэш в data/pages/
  download.py   загрузка изображений в data/img/
  geo.py        модель равнопромежуточной конической проекции (прямая и обратная)
  georef.py     автоматическая привязка по контуру России, порог качества
  vec.py        изображение -> цветовые полигоны в пикселях
  build.py      сборка site/public/data: catalog.json, v/*.json, o/*.jpg, t/*.webp
  check.py      проверка полноты
data/           кэш обхода, изображения, контур России (не в git)
site/public/    index.html, app.js, style.css, vendor/, data/
wrangler.jsonc
```

## Ключевые решения

1. **Проекция**. Параметры `n`, `G` и поворот получены подгонкой по 26 городам на карте
   `tom2/383` (медианная ошибка 6 пикселей). Для остальных карт подбираются только
   масштаб, сдвиг и поворот; затем проекция уточняется.
2. **Привязка**. Контур России (Natural Earth 1:50 млн) проецируется и сопоставляется с
   границами изображения: грубый поиск по масштабам через `matchTemplate`, уточнение
   симплекс-методом по усечённому расстоянию до границ. Привязка принимается, если доля
   точек контура рядом с границами выше порога и заметно выше случайной.
3. **Векторизация**. Тонкие штрихи находятся операциями black-hat и top-hat и заливаются
   цветом ближайшего чистого пикселя; цвета квантуются k-means в Lab; метки сглаживаются
   голосованием; мелкие компоненты присоединяются к соседям; контуры упрощаются.
4. **Формат данных**. Вектор хранится в пикселях оригинала в компактном JSON
   (`colors`, `f: [цвет, внутри_России, кольца]`). Параметры привязки лежат в каталоге.
   Клиент сам переводит пиксели в долготу и широту; GeoJSON для скачивания строится в
   браузере.
5. **Режим «лист»**. Пиксели листа отображаются в условную область карты в проекции
   Меркатора; оригинал подключается как растровый источник по четырём углам.

## Проверка конституции

I — оригиналы копируются в `data/o/` без изменений, источник в каталоге. II — порог в
`georef.py`. III — всё через `pipeline/`. IV — без сборки. V — кэш и 5 потоков.
