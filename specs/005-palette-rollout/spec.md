# Спецификация: классы по легенде по правилу, без списка карт

**Папка**: `specs/005-palette-rollout` | **Создана**: 2026-10-12 | **Статус**: опубликовано 2026-10-12

**Запрос**: перенести классы по легенде на карты, где образцов больше, чем классов. Ответ пользователя: «го».

## Проблема

Фича 004 строит цветовые классы по легенде только для двух карт из списка `LEGEND_PALETTE`.
На остальных картах соседние цвета легенды попадают в один класс. Такой класс остаётся
без подписи или получает чужую подпись.

## Сценарий (P1)

Пользователь открывает карту с подробной легендой и наводит курсор на полигон. Подсказка
показывает подпись знака этого цвета. Если этот цвет в легенде у нескольких знаков,
подсказка показывает их список.

**Проверка**: на картах, которые получили классы по легенде, подписей и списков вариантов
в сумме больше, чем было до изменения.

## Требования

- **FR-001**: Конвейер сам выбирает карты по правилу. Списка карт в коде нет.
- **FR-002**: Правило: цветов в легенде больше, чем классов у образцов легенды после
  первого прохода. Цвета легенды считает `legend.palette`.
- **FR-003**: Конвейер сравнивает оба варианта слоя. Вариант по легенде остаётся,
  если он сохранил образцы легенды. Точное условие записано в `plan.md`.
- **FR-004**: Карта, которая не прошла условие FR-003, сохраняет прежние классы.
- **FR-005**: Метаданные карты хранят признак «классы по легенде». Проверка полноты
  данных показывает число таких карт.
- **FR-006**: Правило FR-002 меняет вектор только выбранных карт.
- **FR-007**: Одинаковый лист даёт одинаковые классы при любом порядке сборки.
- **FR-008**: Слой по легенде отменяется, если из-за него лист становится картинкой.

## Вне рамок

- Чтение номеров знаков на самой карте.
- Новые способы разбора текста.

## Критерии успеха

- **SC-001**: Сумма подписей и списков вариантов на изменённых картах выросла.
- **SC-002**: Каждая карта потеряла меньше 3 подписей. Карта с большей потерей допустима,
  если прежние подписи были ошибочными. Такие карты перечислены в итогах.
- **SC-003**: Число карт с подписями по всему атласу не меньше 735.
- **SC-004**: Размер каждого векторного файла не больше 1,4 МБ. Проверка полноты данных
  не находит ошибок.

## Итог

- Правило FR-002 выбрало 340 карт. Условия FR-003 и FR-008 прошли 167 карт.
- SC-001 выполнен: на 167 картах подписей и списков стало 1793, было 1332. Точных подписей
  стало 1668, было 968.
- SC-002 выполнен: наибольшая потеря — 2 подписи. Потери есть у 6 карт из 167.
- SC-003 выполнен: карт с подписями 746.
- SC-004 выполнен: наибольший файл — 0,86 МБ, проверка полноты данных ошибок не нашла.
- Первая пересборка показала дефект: `cv2.kmeans` брал случайные числа из общего генератора.
  Результат зависел от порядка карт. Отсюда требование FR-007.
- 173 карты из 340 сохранили классы первого прохода. Их слой пересобран с новым начальным числом.
  Подписей на них стало 186, было 155. Потери есть у 11 карт, каждая — 1 или 2 подписи.
- 2 листа стали картинками по правилу `noise`: `1-222-1` и `2-254-257-1`. С новым начальным
  числом первый проход дал на них больше 1500 полигонов.
- Остались ошибки в заголовках групп. Пример: «Эстонцы» в группе «ЧУКОТСКО-КАМЧАТСКАЯ»
  на карте `4-124-125-1`.
