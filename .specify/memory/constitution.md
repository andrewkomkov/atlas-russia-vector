# Конституция проекта atlas-russia-vector

## Принципы

### I. Источник не подменяется
Каждая карта на сайте хранит ссылку на страницу nationalatlas.ru, с которой она взята, и
оригинальное изображение без изменений. Векторный слой — производный продукт, оригинал
всегда доступен для просмотра и скачивания.

### II. Честная привязка
Карта показывается на географической подложке только тогда, когда автоматическая привязка
прошла проверку по контуру России (порог записан в `pipeline/georef.py`). Карта без
подтверждённой привязки показывается в режиме «лист» в пиксельных координатах. Привязка
«на глаз» запрещена.

### III. Воспроизводимый конвейер
Все данные сайта получаются командами из `pipeline/` из исходных страниц и изображений.
Ручная правка файлов в `site/public/data/` запрещена: правится код конвейера, затем данные
пересобираются.

### IV. Статический сайт без сборки
Сайт — статические файлы в `site/public/`, которые раздаёт Cloudflare Workers Static Assets.
Библиотеки попадают в `site/public/vendor/` командой `npm install`; версия зафиксирована в
`site/package.json`. Серверной логики и
баз данных нет.

### V. Бережный обход источника
Обходчик и загрузчик кэшируют всё на диске и не запрашивают повторно то, что уже скачано.
Параллельность — не больше 5 запросов.

## Процесс
Любое изменение идёт через spec-kit: папка `specs/NNN-slug/` с `spec.md`, `plan.md`,
`tasks.md`. Галочка в `tasks.md` ставится после проверки кода, а не по намерению.
